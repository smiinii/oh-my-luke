# 공통 실험 비공개 규칙 v1

- Codex·OMX·OML 모두 같은 규칙을 따른다. 공개 문서 검색과 패키지 다운로드는 허용한다.
- 작업은 제공된 자기 프로젝트에서 수행한다. 로컬 Git 커밋은 허용하지만 실험 중 git push, PR/이슈/Gist 게시, 파일 업로드, 외부 저장소 동기화는 하지 않는다.
- 과제 원문·비공개 코드·답안·로그·결과를 외부 사이트, 검색 질의, 공유 문서, 다른 실험 세션에 보내지 않는다. 검색에는 민감한 원문 대신 일반적인 기술 용어를 사용한다.
- 미리 승인된 AI 제공자에게 현재 작업의 추론에 필요한 입력을 보내는 것은 허용한다. 이는 별도 웹 업로드나 다른 비교군으로의 전달을 허용한다는 뜻이 아니다.
- 현재 실행에 속한 하위 에이전트에도 동일 규칙을 적용한다. 상대 비교군·이전 실행의 파일·대화·로그·답안을 찾거나 받지 않는다.
- 정답 또는 상대 결과를 우연히 보거나 외부 공유가 발생하면 추가 공유를 중단하고 실행 기록에 사실을 남긴다. 숨기거나 기록을 지우지 않는다.
- 한 실행이 끝났다고 공개하지 않는다. 모든 비교 실행 종료, 결과·오염 검토 확정, 인증정보·민감 로그 제거 후 운영자가 별도로 승인한 자료만 공개한다.
- 이 규칙은 운영 계약이며 모든 외부 통신을 기술적으로 차단/검사한다는 보증은 아니다.
