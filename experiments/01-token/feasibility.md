# 현재 제품과 실험 과제의 적합성

2026-09-08 기준. 준비 도구 검증과 제품의 실전 과제 수행 가능성은 다르다. 실제 비교를 시작하지 않았으며, 다음 제약을 [선행 이슈 #37](https://github.com/smiinii/oh-my-luke/issues/37)로 분리했다.

## 과제별 제품 지원

| 과제 | 필요한 능력 | 현재 OML | 다음 확인 |
|---|---|---|---|
| A | 기존 계산기 수정 + 회귀 테스트 추가 | 기존 파일 EDIT 가능, 새 테스트 파일 생성 미지원 | 신규 파일 계약 |
| B | 메서드 추가 + 테스트 추가 | 기존 소스 수정 가능, 테스트 신규 생성 미지원 | 복수 변경의 최종 검증 |
| C | 공통 클래스 생성 + 두 서비스 변경 | 기존 파일 순차 Workflow는 가능, 신규 클래스 생성 미지원 | 상호 의존 파일의 검증·적용 |
| 연습 | 기존 QuantityLabel 수정 | 파일 수정 형태는 현재 계약에 맞음 | 실제 CLI/인증/Java 검증 연결 |

근거는 [작업표 제약](../../docs/start-usage.md), [단일 파일 실행 계약](../../docs/preset-usage.md), [정적 Workflow](../../docs/workflow-usage.md)다. 고정 작업표의 파일 지정과 단계 분해는 사람이 준비한 입력이므로 실제 비교에서는 세 방식에 공개하거나 준비 비용으로 기록한다.

## 빌드 실행

현재 macOS ProcessTool은 최초 실행 파일만 허용하고 자식 실행을 차단한다. `ExperimentGradleCompatibilityTest`가 실험 프로젝트와 실제 Wrapper를 ProcessTool에 전달해 성공하지 못하는 현재 제약을 확인한다. 기존 `MacOsSeatbeltSandboxTest`도 자식 실행 거부를 검증한다.

따라서 별도 실험 평가기의 JDK 컴파일 성공을 OML 내부 Gradle 지원의 증거로 쓰지 않는다. 제품의 고정 검증 경로는 #37에서 보완하고, Linux에서는 JDK·Gradle 배포본·캐시 접근까지 확인해야 한다.

공개 과제의 `./gradlew test`는 별도 준비 CI에서 실행한다. 최종 평가기는 후보가 만든 Gradle 스크립트를 실행하지 않고 고정 JDK 명령을 사용한다.

## 실행기 발견

현재 로컬 PATH에서 Codex CLI 0.153.0을 확인했다. OMX와 설치판 omluke는 찾지 못했다. 이 상태를 사용자에게 설정 질문으로 넘기지 않고 준비 상태 보고서에 남긴다. 실제 실행기 설치·버전·모드 확정은 #35 진입 전 수행한다. OML은 이 저장소에서 개발 빌드를 만들 수 있다.

`bench.py preflight`는 --version만 사용하며 로그인 정보나 실제 토큰 값을 읽지 않는다. 이 출력만으로 인증 성공·모델 사용 가능성을 보장하지 않는다.

## 준비 테스트가 증명하는 것

- 동일 과제의 파일 해시와 시작 커밋이 동일하고 `.git`은 독립적이다.
- A·B·C·연습 원본은 최종 요구사항에 실패하고 기준 구현은 통과한다.
- 정상적인 다른 할인 구현도 통과하며, 빈 테스트·테스트 삭제·빌드 변경·주석만 있는 리팩터링은 실패한다.
- 로컬 상대 파일 접근 차단과 공통 파일 접근, 일반 자식 정리, 출력·시간 한도를 검증한다.
- 토큰 로그의 부모·자식·중복·포크·누락·오류를 합성 샘플로 검사한다.
- 가짜 실행의 성공·실패·시간 초과·환경 오류를 기록하고 같은 JSON에서 보고서를 다시 만든다.

## 실제 실험 전에 남는 조건

1. #37 제품 범위를 구현·검증하고 사용할 OML 버전을 고정한다.
2. OMX 실행 모드·실제 자식 세션 목록·계측 스키마를 확인한다.
3. Linux PID namespace 환경에서 인증과 외부 도구가 같은 격리 경계를 따르는지 확인한다.
4. 로컬뿐 아니라 원격 공개 기준 구현과 결과의 재접근 경로를 다룬다.
5. 모델·추론·공통 도구·캐시 조건을 고정하고 예비 실험을 수행한다.

이 조건을 해결하기 전에는 준비 테스트 통과를 근거로 `liveReady`를 true로 바꾸지 않는다.
