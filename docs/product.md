# Product

## 한 문장

Oh My Luke는 사용자가 이미 로그인한 AI CLI를 실행기로 사용하면서 컨텍스트, 실패 이력, 검증, 호출 예산을 관리해 최소한의 AI 실행으로 완료 조건에 도달하도록 돕는 Java 기반 로컬 런타임이다.

## MVP

- AI 없이 실행 가능한 단일 그래프 커널
- Direct, Loop, 정적 Workflow 프리셋
- JSON 체크포인트와 JSONL 이벤트 로그
- 객관적인 완료 조건과 안전 중단 조건
- 프로젝트 경계와 기억되는 능력 기반 도구 권한
- 첫 BYOR 실행기인 Codex CLI
- 실행별 토큰과 호출 횟수 측정

## MVP 제외

- 중앙 계정과 결제
- 웹 서버와 GUI
- 데이터베이스와 클라우드 동기화
- AI가 임의로 생성하는 동적 그래프
- 여러 AI 실행기의 자동 라우팅
- 기본 병렬 AI 호출
- OML 자체 서브 에이전트 분업·관리 기능
- OML 자체 스킬 탐색·선택·로딩 시스템
- 사용자 승인 없는 프로젝트 자동 배포

## 서브 에이전트·스킬 보류 결정

2026-08-31 결정이며, 두 기능의 MVP 범위는 이 문서를 최신 기준으로 삼는다.

- **결정:** OML 자체 서브 에이전트 분업과 스킬 시스템은 첫 MVP에서 보류한다. 현재 AI 작성자와 Java·고정 명령 검사자, 기존 Direct·Loop·Workflow 흐름은 유지한다.
- **이유:** 기능 확장보다 실행 안정성, 실제 작업의 성공률·사용량 검증과 사용성 개선에 집중한다. 여러 AI 호출이나 긴 스킬 입력이 토큰을 자동으로 절약한다고 가정하지 않는다.
- **재검토 조건:** 실제 작업과 비교 실험에서 기존 흐름으로 해결하기 어려운 역할 분리나 반복 지침의 필요성이 확인되면 MVP 이후 검토한다. 추가 호출·입력 비용과 성공률을 함께 측정한 뒤 도입 여부를 정한다.
- **적용 범위:** OML 제품이 직접 제공하는 기능에 대한 결정이다. OML을 개발·리뷰할 때 사용하는 서브 에이전트·스킬을 금지하거나, 연결한 AI 실행기의 기존 기능 전체를 끄겠다는 뜻은 아니다.

## 제품 배포 원칙

- 코어와 개발 기준은 Java 21로 유지한다.
- 사용자는 OML 자체 실행을 위해 Java나 Node.js를 별도로 설치하지 않는 것을 목표로 한다. 연결할 AI CLI의 요구사항은 별도다.
- 첫 공개 배포 파일은 OML 전용 Java 런타임을 포함한 운영체제별 패키지로 만든다.
- GitHub Releases를 배포 파일의 단일 기준으로 사용한다.
- 설치 검증 후 macOS는 Homebrew, Windows는 WinGet으로 같은 배포 파일을 제공한다.
- Linux는 우선 GitHub Releases에서 제공하고 수요에 따라 패키지 관리자를 추가한다.
- npm 배포는 계획하지 않는다.
- GraalVM Native Image는 기본 구조가 아니라 용량과 호환성을 측정한 뒤 선택하는 최적화 수단이다.

## 첫 번째 마일스톤

AI, 파일 수정, 셸 명령 없이 메모리에서 다음 그래프를 실행한다.

```text
A → 검사
    ├─ PASS → END
    └─ FAIL → A
```

통과 조건:

- 같은 입력이 같은 경로를 선택한다.
- 상태 변경과 선택 이유를 기록한다.
- 잘못된 그래프와 무제한 순환을 실행 전에 거부한다.
